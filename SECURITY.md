# Security policy

## Supported versions

Syncplayer is currently an experimental prototype. Only the latest revision of `main` receives
security fixes; there are no supported releases yet.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/arturormk/syncplayer/security/advisories/new)
to share a description, reproduction steps, affected versions, and any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow time to investigate and
prepare a fix before publishing details.
